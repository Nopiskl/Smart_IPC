## 板端验收步骤

1. 核对固件 libc、传感器、IQ 文件和 CMA 配置；停止原摄像头服务。
2. 启动 SmartIPC，检查页面媒体状态并使用 VLC 连续拉流。
3. 验证检测类别、框坐标、画面色彩、阈值切换和关闭/开启检测。
4. 分别获取 JPEG、BMP 截图，检查图像尺寸、质量及叠加开关。
5. 修改帧率、码率、GOP 和分辨率，等待 task 成功后重连 RTSP；尝试传感器不支持的配置，检查失败信息及恢复行为。
6. 重启程序，检查已生效配置和账号是否保留。
7. 分别运行两个基础示例，确认采集、FPS 叠加和推流。
8. 连续运行并重复截图/修改配置，观察 MemAvailable、CMA、帧率和驱动内存；发送 SIGTERM 后确认可以重新占用摄像头及端口。

物理电机驱动等待具体硬件方案。当前可验证 disabled 返回和 simulated 命令行为，不能据此判定真实电机动作成功。
